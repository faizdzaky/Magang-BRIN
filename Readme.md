# Dokumentasi & Repositori Pembelajaran Pemrograman Embedded Systems

Folder ini berisi latihan, kode program hasil pembelajaran, dan rangkaian dari KiCad yang dilakuakn selama magang di Brin.

## 📁 Struktur dan Isi Folder

Berikut adalah penjelasan fungsi dan cakupan materi dari masing-masing folder di dalam repositori ini:

### 1. `01-Kodingan/`
Folder ini berisi latihan dan kode program hasil pembelajaran mengenai pemrosesan sinyal digital, komunikasi mikrokarakter/mikroprosesor, serta pengontrolan I/O.
* **Materi:** Pembelajaran dari kodingan tentang ADC, Blok dan nonblok, serialport, onewire, LED, dan digital input output.

### 2. `02-PCB/`
Folder ini berisi latihan pembuat PCB di kiCad dari rangkaian simpel sampai ke rangkaian yg lebih advanced.
* **Materi:** beberapa rangkaian PCB yang telah dibuat seperti simpel, advanced, platform arduino pro mini, dan kontrol tomografi.

---

## 🛠️ Prasyarat & Perangkat yang Digunakan buat kodingan
* **Hardware:** Mikrokontroler (Arduino), LED, Resistor, Potensiometer/Sensor Analog, Sensor OneWire (DS18B20).
* **Software/IDE:** Arduino IDE / VS Code + PlatformIO.

## 🛠️ Prasyarat & Perangkat yang Digunakan buat kodingan
* **Software/IDE:** KiCad.
